# Курсы KTouch

Восемь новых курсов преобразованы из репозитория KDE KTouch на коммите `f0dea77d84c4ddd880074a8eed81e573189ea53b`. Источник каждого файла — `data/courses/<имя>.xml` в этом коммите:

| Язык | Код | Файл | Раскладка XML | Уроков |
| --- | --- | --- | --- | ---: |
| Английский | `en` | `us.xml` | `us` | 15 |
| Русский | `ru` | `ru1.xml` | `ru` | 16 |
| Испанский | `es` | `es1.xml` | `es` | 15 |
| Арабский | `ar` | `ara.xml` | `ara` | 13 |
| Французский | `fr` | `fr.xml` | `fr` | 28 |
| Португальский (Бразилия) | `pt-BR` | `br.xml` | `br` | 11 |
| Немецкий | `de` | `de1.xml` | `de` | 50 |
| Итальянский | `it` | `it.xml` | `it` | 60 |
| Турецкий | `tr` | `tr.xml` | `tr` | 15 |
| Персидский | `fa` | `ir.xml` | `ir` | 13 |

В метаданных английского курса указаны Steinar Theigmann и Håvard Frøiland; русский курс адаптировал Chemisov Konstantin из ktouch-gen. Описания XML указывают авторов и происхождение курсов: испанский — Steinar Theigmann и Håvard Frøiland, французский — Håvard Frøiland, бразильский португальский — Ari Caldeira, немецкий — Markus Frisch, арабский — Fahad Alsaidi, персидский — Сейед Али Акбар Наджафиан. Итальянский курс ссылается на «Appunti di informatica libera», турецкий описан как созданный Zemberek.

Каждый элемент `<lesson>` преобразован в отдельный UTF-8 JSON по исходному порядку. Пробельные символы текста сведены к одному пробелу; название, новые символы и язык сохранены. ID имеет вид `ktouch.<имя XML без расширения>.<номер урока>`. Код языка задаётся отдельно от имени курса и раскладки: `br.xml` — `pt-BR`, `ir.xml` — `fa`.

[Руководство KTouch](https://docs.kde.org/stable_kf6/en/ktouch/ktouch/ktouch.pdf) указывает GPL версии 2 для данных, включаемых в стандартную поставку. Текст [GPL-2.0-or-later](GPL-2.0-or-later.txt) взят из репозитория KTouch. В XML нет отдельного лицензионного заголовка. До внешней публикации подтвердите условия именно этих файлов и совместимость с лицензией проекта.

В арабском уроке 11 после `)` удалена одиночная латинская `f` из исходного XML: её нет в схеме `ara`, а окружающий текст арабский. Это единственное исправление содержимого сверх нормализации пробелов.
