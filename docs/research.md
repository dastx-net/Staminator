# Исследование исходников Stamina

Статус: первичный статический обзор исходников в локальном `../Stamina` и инвентаризация установленной копии `src/stamina_setup`. Поведение в работающем приложении ещё не проверено.

## Состав и сборка

В каталоге есть проект Microsoft Developer Studio 5.0 (`Stamina.dsw`, `Stamina.dsp`), 44 файла `.cpp`, 46 файлов `.h`, ресурсы Win32 (`Stamina.rc`, `RES/`), FMOD 3.x и JPEG-библиотека. Проект настроен как 32-разрядное Windows-приложение с MFC; в конфигурациях встречаются пути и команды сборки, зависящие от старой машины. Современной сборочной конфигурации и тестов нет. Успешная сборка в текущем окружении не подтверждена.

В исходниках также есть файлы состояния старой IDE (`.aps`, `.ncb`, `.opt`, `.plg`). Это не исходные данные приложения.

## Подтверждённые функции

| Область | Поведение в исходниках | Где смотреть |
| --- | --- | --- |
| Режимы | `MODE_LESSON`, `MODE_TEXT`, `MODE_MIXED_TEXT`, `MODE_EVENLY`, `MODE_BOOK`: урок, фразы, буквы из фраз, все клавиши, внешний текст | `Stamina.h`, `Stamina.rc`, `Stamina.cpp::StartGame` |
| Ввод | Ожидаемый символ сравнивается с введённым. Верный продвигает позицию, неверный увеличивает счётчик ошибок; есть сопоставление некоторых типографских знаков с клавиатурными | `MainWnd.cpp::OnChar`, `TextField.cpp` |
| Сеанс | Таймер запускается с первым вводом. Есть старт/стоп, пауза, длительность сеанса и переход к следующему фрагменту текста | `Stamina.cpp::StartGame`, `StartTimers`, `StopGame`, `PauseGame`; `MainWnd.cpp::OnChar` |
| Метрики | Скорость считается в символах в минуту; интерфейс умеет показывать слова в минуту через деление на 5. Процент ошибок — ошибки / (верные символы + ошибки) × 100 | `Stamina.h::CalcSpeed`, `Stamina.cpp::StopGame`, `DlgResult.cpp` |
| История | Результаты сохраняются по пользователю и раскладке; есть просмотр графика. Запись в историю происходит для режимов фраз и внешнего текста, если выполнен порог времени (по умолчанию 120 с) | `Progress.cpp`, `DlgProgress.cpp`, `Stamina.cpp::StopGame`, `Options.cpp::Clear` |
| Контент | Уроки можно редактировать и генерировать, фразы добавлять, внешний файл выбирать и продолжать с сохранённой позиции | `Lessons.cpp`, `DlgLessons.cpp`, `DlgAddText.cpp`, `Book.cpp`, `DlgBook.cpp` |
| Пользователи | Создание, выбор, переименование и удаление профилей; настройки и история привязаны к профилю | `User.cpp`, `DlgUsers.cpp`, `DlgNewUser.cpp` |
| Интерфейс | Экранная клавиатура с подсветкой следующей клавиши, смена раскладки, параметры шрифтов/цветов/скинов | `KeybWnd.cpp`, `PageKeyb.cpp`, `PageView.cpp`, `Stamina.rc` |
| Аудио | Звуки событий, музыка, плейлист и управление громкостью через FMOD | `Sound.cpp`, `Music.cpp`, `DlgPlaylist.cpp`, `PageSound.cpp` |

Дополнение для реализации: `Stamina.cpp::PauseGame(false)` снимает паузу, но оставляет таймер остановленным; он снова запускается при следующем вводе (`MainWnd.cpp::OnChar`). Поэтому время ожидания после снятия паузы не входит в скорость. Режим `MODE_MIXED_TEXT` выбирает случайные символы из файла фраз, пропуская переводы строк и повторные пробелы. `MODE_EVENLY` перемешивает символы текущей раскладки, исключает символы из `caps` и вставляет пробелы группами (`Text.cpp::GetNewPhrase`). В режиме фраз `CText::GetNewPhrase` читает строку с индексированного смещения, обрезает её по первому `.`, `?` или `!` и добавляет один или два пробела согласно настройке.

`Text.cpp::NewRandomOrder` перемешивает оставшуюся часть индекса фраз; полный запуск сбрасывает индекс и перемешивает все записи. `GetNewPhrase` после конца индекса возвращается к началу. Порядок и сохранение индекса ещё требуют проверки на копии оригинала.

Дополнительный статический разбор: `MainWnd.cpp::OnChar` запускает отсчёт и на первой ошибке, Esc вызывает остановку, а символ при паузе снимает её без зачёта ввода. `Stamina.cpp::OnTimer` не завершает урок по пользовательскому таймеру; значение по умолчанию — 300 секунд (`Options.cpp::Clear`). `Book.cpp::GetNewPhrase` сворачивает пробельные символы, а `SavePosition` рассчитывает позицию исходного файла по фактически введённым символам; чтение вперёд само по себе не означает прохождения. В `Options.cpp` сохраняются путь и позиция книги, ширина и видимость клавиатуры; сохранение произвольного расположения всех окон этим не подтверждается. Это выводы по исходникам, не проверка работающей программы.

`Stamina.rc::IDR_MAIN` связывает F1 с переключением раскладки, F2 с клавиатурой, F3 с настройками, F4 с редактором уроков, F5 с прогрессом, F6 с профилями, F8 с музыкой и F12 с плейлистом; `MainWnd.cpp::OnKeyDown` обрабатывает Pause. `PageSound.cpp` содержит отдельные регуляторы громкости, `PageView.cpp` — выбор изображения или цвета, `PageKeyb.cpp` — параметры клавиатуры. Пункт логической игры есть в `Stamina.rc`; изученные исходники не подтверждают наличие предложенных в плане аркад или отдельного окна рук. Все выводы требуют проверки работающей копии.

Выбор следующего и предыдущего урока работает только вне сеанса и пропускает записи меню, у которых тип не `' '` (`MainWnd.cpp::OnNextLesson`, `OnPrevLesson`; `Lessons.cpp::GetNextTextLessonID`, `GetPrevTextLessonID`). Завершение и ручная остановка открывают один и тот же диалог результата (`Stamina.cpp::StopGame`, `DlgResult.cpp`). При ручной остановке до конца текста диалог разрешает продолжить занятие; после полного урока продолжение недоступно, а кнопка завершения автоматически выбирает следующий текстовый урок. В режиме фраз новые фрагменты добавляются в текущий сеанс без сброса счётчиков (`MainWnd.cpp::OnChar`, `Text.cpp::GetNewPhrase`).

## Установленная копия и данные

В `src/stamina_setup` теперь есть установленная программа и добавленные пользователем материалы: 498 файлов общим размером около 39,7 МБ. Папка исключена из Git из-за личного профиля, исполняемых файлов и сторонних медиаматериалов. Количества ниже описывают именно эту локальную копию, а не состав обычного дистрибутива Stamina.

| Путь | Найдено | Для чего полезно |
| --- | --- | --- |
| `Stamina.exe`, `fmod.dll`, `uninstall.exe`, `Help.chm` | исполняемая программа, звуковая библиотека, деинсталлятор и справка | визуальная и поведенческая проверка на отдельной копии |
| `Data/` | 45 файлов: 21 `lessons.*`, 24 `phrases.*` | уроки и фразы для изучения форматов и сценариев |
| `Language/`, `Layouts.ini` | 11 языковых INI и таблица раскладок | локализация и соответствие раскладки файлам данных |
| `Skins/` | 17 JPEG-изображений и 2 файла скинов клавиатуры без расширения | оформление и внешний вид экранной клавиатуры |
| `Sound/`, `Music/`, `Menu/` | 310 MP3, 56 MP3 и 48 WAV | звуковые события, музыка и звуки меню |
| `Users/Dan/` | `Options.ini`, `Playlist.m3u`, `random.ru`, `random.en` | пример личных настроек и служебных индексов; содержимое не публиковать |

Пути к каталогам определены в `Strings.cpp`; загрузка раскладок и языка — в `Stamina.cpp` и `Language.cpp`. Код также ссылается на `Words`, но в этой установке такого каталога нет. Отдельных внешних книг для режима файла в каталоге тоже не обнаружено.

Проверка кодировок показала, что русские уроки, фразы, языковой INI и `Layouts.ini` читаются как Windows-1251. Два файла `Skins/Keyboard/black` и `white` без расширения начинаются с сигнатуры JPEG. При анализе нельзя без проверки считать все файлы UTF-8 или классифицировать бинарные данные по расширению.

`Data/lessons.ru` начинается с маркеров вида `[#]>Название раздела` и `[#] Название урока`; текст упражнения идёт после заголовка. В `Lessons.cpp::find_next_lesson` предусмотрены типы ` `, `>`, `-`, `<`, а `CLessons::Save` записывает разделы в формате `[#]<тип><имя>` с CRLF. `Data/phrases.ru` и `phrases.en` содержат текстовые фразы построчно. В примерах около 4000 русских и 1081 английская непустая строка; это число строк, не обязательно число единиц, которые реально индексирует программа.

`Layouts.ini` содержит 76 активных записей раскладок в секции `[LAYOUTS]`; каждая связывает код раскладки, расширение файла фраз, расширение файла уроков, имя и набор символов. Реально доступный пользователю набор зависит от установленных в Windows раскладок (`Stamina.cpp::LoadLayouts`). Индексы порядка фраз записываются в `Users/<профиль>/random.<расширение>`; по `Text.cpp` это бинарный файл с заголовком и массивом смещений.

История записывается в `Users/<профиль>/progress.<расширение раскладки>` строками с датой, скоростью, процентом ошибок и длительностью (`Progress.cpp`). Настройки хранятся в `Users/<профиль>/Options.ini` (`User.cpp`). Перед проектированием импорта нужно уточнить полную семантику маркеров уроков и алгоритм выделения фраз из текста.

## Редактор и добавление фраз

`DlgLessons.cpp::OnGenerate` вставляет последовательность для выбранных символов. `Lessons.cpp::GenerateSeq` и `seq` задают фиксированные шаблоны для 1–4 символов. `DlgAddText.cpp::OnBrowse` индексирует предложения из выбранного файла, а `OnAdd` передаёт их в `Text.cpp::AddFrom`. В клоне фразы вводятся строками и хранятся в отдельных UTF-8 файлах; импорт файлов и старого формата здесь не реализован.

## Зоны пальцев цифрового ряда

В `apps/desktop/src/keyboard.rs` принята схема: левая рука — 1 мизинец, 2 безымянный, 3 средний, 4–5 указательный; правая — 6–7 указательный, 8 средний, 9 безымянный, 0 мизинец. Она совпадает с [учебным пособием по работе с клавиатурой, раздел 3.1.5](https://www.mohp.gov.eg/theducation/SecondGroup/Medical_registration_and_statistics/Term2/Data_entry_and_analysis/Data_entry_and_analysis.pdf) и применяется к физическим клавишам в обеих раскладках.

Существуют и другие схемы: например, [самоучитель Леонова](https://ru.djvu.online/file/vyYGgcPnZXLqT) относит 4 к левому среднему, а 5 и 6 — к левому указательному. Поэтому текущую схему нельзя считать единственно возможной. Выбор схемы предусмотрен в [плане настройки клавиатуры](plan/todo/custom-keyboard.md). В оригинале `CKeybWnd` рисует разделители зон, а `CPageKeyb` предлагает три варианта их вида; полное соответствие этих вариантов назначениям пальцев не проверено.

## Что уточнить до реализации

1. Целевая платформа и стек нового приложения: Windows desktop, web или другой вариант.
2. Нужен ли точный визуальный паритет с оригиналом, включая оформление и звук, или достаточно функционального паритета.
3. Какие из доступных уроков, фраз, раскладок, локализаций и ресурсов можно использовать как данные нового приложения после проверки прав.
4. Нужна ли миграция старых профилей и статистики.
5. Какое поведение устаревших функций сохранить: регистрация/пробная версия, интеграции с внешними программами, старые форматы плейлистов.
6. Правовой статус исходников и ресурсов для предполагаемого способа распространения.
7. Поведение установленной программы в реальных сценариях: запуск, выбор раскладки, ввод, завершение, настройки, редакторы и сохранение данных. Проверять на копии, чтобы не менять `Users/Dan`.

## Предварительный порядок функционального паритета

1. Модель сеанса, сравнение символов, таймер, пауза, завершение и расчёт метрик.
2. Режимы уроков, фраз и внешнего файла; затем генеративные режимы.

4. Редактирование контента, экранная клавиатура и поддержка раскладок.

Этот порядок — рабочая гипотеза для планирования, не обещание точного состава первого релиза.

## Геометрия окон клона

- `egui` 0.37 передаёт размер и координаты viewport в логических единицах; `egui-winit` переводит позицию через масштаб текущего окна. На Wayland координаты окна недоступны, размещение определяет композитор.
- `egui` не предоставляет список рабочих областей мониторов. В Windows клон получает его через `EnumDisplayMonitors` и `GetMonitorInfoW`.
- На Windows проверены перемещение и изменение размеров обоих окон, перезапуск и сохранение закрытой клавиатуры в отдельном временном профиле. Разные DPI, отключение монитора и Wayland требуют проверки на соответствующих системах.
