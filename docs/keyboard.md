# Клавиатуры

В комплект входят ANSI QWERTY, Soft Pink ANSI и чёрная разделённая клавиатура. Дополнительные клавиатуры добавляются при первом запуске и не восстанавливаются автоматически после удаления. У Split Black ANSI один пробел слева: две отдельные клавиши с одинаковым физическим кодом пока не поддерживаются. Откройте «Опции → Клавиатуры». Здесь можно выбрать клавиатуру, создать её копию в редакторе, импортировать или экспортировать ZIP и удалить ненужную клавиатуру. Последнюю клавиатуру удалить нельзя. Выбор сохраняется в профиле.

Редактор меняет размеры холста, положение и форму клавиш, физический код, подписи, цвет и палец. Прямоугольник можно перетаскивать и менять за нижний правый угол; полигон — перетаскивать и менять за вершины. Подпись может следовать раскладке RU/EN, быть пустой или содержать свой текст. Сохранение создаёт новую копию.

Папки клавиатур находятся рядом с базой приложения: в Windows это `%APPDATA%/Staminator/Keyboards`, в других системах — каталог `Staminator/Keyboards` внутри `XDG_CONFIG_HOME` или `~/.config`. Имя папки может содержать латинские буквы, цифры, `-` и `_`. В каждой папке нужен UTF-8 файл `keyboard.json`. ZIP содержит этот файл в корне и может содержать дополнительные файлы и вложенные папки. При загрузке исходная схема ANSI из предыдущей версии выравнивается в памяти; её файл не меняется. Пользовательские схемы сохраняют свою геометрию. Импорт создаёт отдельную папку и не перезаписывает существующую. Экспорт не перезаписывает существующий файл. Пределы: 16 записей в архиве, 2 МиБ для архива и распакованных данных, 1 МиБ для одного файла.

Схема версии 1 задаёт `name`, `canvas` с `width` и `height`, и массив `keys`. У каждой клавиши есть `physical_id` в нотации `KeyboardEvent.code` и `geometry` с формой `rect` (`x`, `y`, `width`, `height`) или `polygon` (`points` с координатами `x`, `y`). Дополнительные поля `label`, `shifted_label`, `color` (`#RRGGBB` или `#RRGGBBAA`) и `finger` необязательны. Отсутствующая подпись использует символ раскладки, пустая строка скрывает подпись. Коды клавиш не зависят от символов. Параметр `show_finger_colors: false` отключает цвета зон пальцев, сохраняя подсветку следующей клавиши и подсказку рук. Необязательный объект `style` задаёт `background_color`, `text_color`, `active_color`, `active_border_color`, `shadow_color`, относительное скругление `key_corner_radius` от 0 до 0,5 и шрифт `font: "soft"`; цвета используют `#RRGGBB` или `#RRGGBBAA`. Мягкий шрифт использует Segoe UI Light, если он доступен в Windows; иначе применяется обычный шрифт интерфейса.

Пример `keyboard.json`:

```json
{
  "version": 1,
  "name": "Моя клавиатура",
  "canvas": { "width": 4, "height": 2 },
  "keys": [
    {
      "physical_id": "KeyA",
      "geometry": { "shape": "rect", "x": 0, "y": 0, "width": 1, "height": 1 },
      "label": "",
      "shifted_label": "",
      "color": "#4488AA",
      "finger": "left_little"
    }
  ]
}
```

В окне доступны две встроенные схемы пальцев: «Книжная» — цифры 1–5 левой рукой и 6–0 правой; «Естественная» — цифры 1–6 левой рукой и 7–0 правой. Во второй схеме 1–2 набирают левым мизинцем, 3 — безымянным, 4 — средним. Названия вариантов цифрового ряда условно использует [пособие Ильи Тероха, тема 12](https://studfile.net/preview/22054648/page%3A4/); они не означают общепринятого стандарта. Кнопка создания схемы делает копию текущего распределения; назначения можно изменить для каждой клавиши. Пользовательскую схему можно сохранить в профиле, экспортировать в JSON и импортировать в другой профиль. Имена встроенных схем зарезервированы. Клавиатура и подсказка рук используют одно распределение.

Подсказка следующей клавиши использует встроенные соответствия для стандартных RU и EN; произвольные системные раскладки, IME и неоднозначные символы не гарантируют однозначного соответствия. Физический код в файле не является проверкой реальной раскладки операционной системы.
