# Уроки в JSON

Приложение однократно импортирует пользовательские уроки в SQLite; новые и изменённые уроки сохраняются в базе. Исходные JSON-файлы остаются на месте. Неизменённые встроенные уроки обновляются при запуске. Изменённые пользователем уроки сохраняются в базе и не заменяются при обновлении. В окне выбора урока можно импортировать или экспортировать отдельный JSON-файл. Подробнее: [ADR 0006](adr/0006-sqlite-storage.md).

Один UTF-8 файл `.json` содержит один урок для первоначального импорта. В Windows прежний пользовательский каталог — `%APPDATA%\Staminator\lessons`. Нажмите «Занятие», выделите урок и просмотрите его описание и текст. Нажмите «Выбрать» или дважды щёлкните урок. В редакторе можно создать или изменить любой урок и добавить упражнение по 1–4 символам.

Встроенные курсы KTouch для русской и US-раскладки находятся в `lessons` рядом с исполняемым файлом. Источник и условия распространения указаны в [lessons/README.md](../lessons/README.md). При разработке используется каталог `lessons` в корне проекта. При упаковке приложения каталог нужно разместить рядом с программой. Фразы также загружаются из локальной установки Stamina. В режиме фраз откройте «Занятие → Добавить фразы»: каждая непустая строка сохраняется для выбранного языка в UTF-8 в пользовательской папке `Staminator/phrases/ru` или `en`.

Пример:

```json
{
  "version": 1,
  "id": "my.ru.first",
  "title": "Первый урок",
  "language": "ru",
  "description": "Короткое упражнение",
  "text": "мир и дом"
}
```

`version` — число `1`. `id`, `title` и `text` — непустые строки; `id` должен быть уникален во всех каталогах. `language` — тег из 2–8 латинских букв и необязательных частей из 1–8 латинских букв или цифр через дефис; это синтаксическое подмножество BCP 47 без проверки реестра; в интерфейсе доступны уроки с основным языком `ru` или `en`. `description` необязателен. Символы пробела в тексте сохраняются. Порядок уроков определяется ID. Символические ссылки при обходе пропускаются.

При первоначальном чтении совпадающие ID исключаются с диагностикой. Редактор проверяет поля и уникальность ID. Изменение ID существующего урока пока не поддерживается.
