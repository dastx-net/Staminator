# Уроки в JSON

Один UTF-8 файл `.json` содержит один урок. Папки внутри каталога образуют группы в списке. В Windows пользовательский каталог — `%APPDATA%\Staminator\lessons`; его путь показан в окне выбора урока. Создайте каталог при необходимости. Добавьте файл и нажмите «Обновить список уроков». Приложение не изменяет эти файлы.

Встроенные уроки находятся в `lessons` рядом с исполняемым файлом. При разработке используется каталог `lessons` в корне проекта. При упаковке приложения каталог нужно разместить рядом с программой. Фразы пока загружаются отдельно из локальной установки Stamina.

Пример:

```json
{
  "version": 1,
  "id": "my.ru.first",
  "title": "Первый урок",
  "language": "ru",
  "description": "Короткое упражнение",
  "text": "мир и дом"
}
```

`version` — число `1`. `id`, `title` и `text` — непустые строки; `id` должен быть уникален во всех каталогах. `language` — тег из 2–8 латинских букв и необязательных частей из 1–8 латинских букв или цифр через дефис; это синтаксическое подмножество BCP 47 без проверки реестра; в интерфейсе доступны уроки с основным языком `ru` или `en`. `description` необязателен. Символы пробела в тексте сохраняются. Порядок уроков определяется ID. Символические ссылки при обходе пропускаются.

Ошибки и пути файлов показаны в окне выбора. При совпадении ID все конфликтующие уроки исключаются до исправления; остальные доступны. Обновление списка не меняет пользовательские файлы. Редактор, генерация уроков и добавление фраз запланированы отдельно.
