# Переводы интерфейса

Встроенные ресурсы находятся в `crates/core/resources/*.json`. Это UTF-8 JSON-объекты. Все десять каталогов содержат одинаковый набор ключей. `_locale` задаёт правила множественного числа. Русский — запасной язык: если в выбранном каталоге нет ключа, программа берёт русское значение и пишет диагностику в стандартный поток ошибок. Если ключа нет нигде, показывает `⟦ключ⟧`.

Значение — строка или объект форм множественного числа. Подстановки записываются как `{name}`, число — как `{count}`. Не меняйте имена подстановок в переводе. В русских формах нужны `one`, `few`, `many`, `other`, в английских — `one`, `other`. При отсутствующем аргументе его имя остаётся в тексте, а программа пишет диагностику.

При добавлении ключа обновите все каталоги. Запустите `cargo test -p staminator-core localization` и `./scripts/check-utf8.ps1`. Тест сверяет ключи и имена подстановок. Проверьте также новое сообщение в окне: длина перевода может отличаться.

Язык выбирается в меню «Опции → Язык интерфейса» и сохраняется отдельно для каждого профиля. Язык упражнения и раскладка не меняются. Новые встроенные языки требуют добавить каталог, выбор языка, правила форм и тесты. Установка внешних переводов пока не поддерживается.

## Проверка обзора

Второй обзор Antigravity отнёс `thread_local` к P1: по его версии тесты используют общий поток. Проверка текущего `rustc --test` с `--test-threads=1` дала разные идентификаторы потоков для двух тестов (`ThreadId(2)` и `ThreadId(3)`); параллельные тесты не разделяют `thread_local`. Вывод обзора о гонке на этой конфигурации не подтверждён. Это не гарантия поведения другого тестового harness.

Обзор также предположил ошибку кодирования расширенных клавиш. Для `0x11d << 16` результат — `0x011d0000`: scan code занимает биты 16–23, признак extended — бит 24. Повторное чтение файлов при смене языка остаётся возможной задержкой на медленном диске.

Новые записи истории хранят коды режима `mode.*` и раскладки `layout.ru`/`layout.en`. Экран прогресса также распознаёт старые русские и английские значения; это сохраняет читаемость прежних профилей.
