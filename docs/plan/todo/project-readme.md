# README проекта

Подготовить понятный README для пользователей и разработчиков: назначение проекта, возможности и текущий статус, установка и запуск на поддерживаемых системах, сборка, расположение пользовательских данных и ссылки на документацию.

**Предложение:** добавить скриншоты после проверки прав на их публикацию, описание способов участия и ссылки на лицензии. Решить, нужны ли отдельные версии README на русском и английском.

## Аналитика

**Основа:** README описывает клон, не доказывает поведение оригинала. Сверять фактические возможности с `apps/desktop` и [планом](../../implementation-plan.md), права — с [подготовкой к публикации](github-release.md).

**Реализация:** написать краткие разделы: назначение и статус, поддерживаемые ОС с пометкой проверенных, требования и команды сборки/запуска, управление, расположение данных, известные ограничения, участие и ссылки на документы. Зависимость текущего каталога контента от локальной установки описать точно; не обещать самостоятельную поставку до её готовности. Ссылку на лицензию добавлять после решения о ней. Начать с русского; английскую версию поддерживать после согласования и указать, какой текст основной.

**Приёмка:** новый разработчик выполняет команды из чистой копии и понимает, какие данные нужны; ссылки работают, утверждения соответствуют текущей сборке. Скриншоты и материалы включать после проверки прав.
