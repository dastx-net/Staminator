# Тестирование интерфейса

**Приоритет:** первая очередь, до новых продуктовых функций. [Долг по тестам](../done/unit-test-debt.md) закрыт.

## Задача

Внедрить автоматические проверки текущего интерфейса и описать ручные системные проверки. Подход и список сценариев — в [документации UI-тестов](../../ui-tests.md); `egui_kittest` пока не подключён.

## Реализация

1. Проверить прототип `egui_kittest`, совместимый с `egui` проекта: ввод, элементы, отдельный viewport, шрифты и локальный запуск. Если инструмент не подходит, зафиксировать ограничения и выбрать рабочую альтернативу.
2. Изолировать время, хранилище, звук и файловые диалоги; тесты используют собственные данные и не трогают пользовательский профиль или установку Stamina.
3. Автоматизировать доступные сценарии: старт, верный и неверный ввод, паузу, результат, выбор и смену профиля, режим, видимость клавиатуры и подсветку. Проверять текущее поведение; отсутствующие возможности покрывать вместе с их реализацией.
4. Добавить ограниченный набор проверяемых снимков ключевых состояний, если рендерер стабилен локально. Зафиксировать размер, DPI, шрифты и данные; изменения эталонов просматривать.
5. Составить и выполнить на Windows ручной чек-лист реального ввода RU/EN, фокуса, отдельного окна, системных диалогов, DPI и звука. Сравнение с оригиналом выполнять на копии установки.

## Готовность

- Автоматические UI-тесты запускаются локально с `cargo test --workspace`; проверки чувствительны к ошибкам поведения.
- Результаты прототипа и ограничения viewport и рендеринга документированы; снимки проверяются в воспроизводимой среде либо указана подтверждённая причина и выбран другой способ проверки вида.
- Ручной чек-лист выполнен на Windows, результаты и найденные расхождения записаны. Другие ОС проверяются при заявлении их поддержки.
- Покрытие UI учитывается в общем отчёте; достижение 95% — критерий связанной задачи о долге.
