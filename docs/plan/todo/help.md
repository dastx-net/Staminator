# Справка и горячие клавиши

Добавить в приложение раздел справки с понятным описанием управления и действий. Состав горячих клавиш ещё нужно сверить с оригиналом.

## Аналитика

**Оригинал:** `Stamina.rc::IDR_MAIN` назначает F1 смене раскладки, F2 клавиатуре, F3 настройкам, F4 редактору, F5 прогрессу, F6 профилям, F8 музыке, F12 плейлисту, стрелки — урокам/громкости, Tab — следующей композиции, Alt+F — выбору файла. `MainWnd.cpp::OnChar` обрабатывает Enter/пробел для старта и Esc для остановки, `OnKeyDown` — Pause. Цифры режимов обрабатываются вне занятия; доступность команд зависит от состояния. Это статический обзор; раскладки и конфликты нужно проверить вручную.

**Реализация:** единый реестр команд с ID, локализованным названием, сочетанием и условиями доступности; меню, обработчик и окно справки используют одну модель. Сохранить привычные сочетания оригинала там, где они доступны в ОС; F1 не назначать справке, если он меняет раскладку. Справка открывается из меню, работает без сети, описывает старт, паузу, остановку, режимы и настройки. Горячие клавиши не перехватывают ввод в текстовых полях и диалогах; на macOS системные ограничения проверить отдельно.

**Приёмка:** каждая отображаемая команда действительно работает в указанном контексте; набор букв и редактирование полей не запускают команды. Проверить RU/EN и доступность справки с клавиатуры, сверить основные сочетания с копией оригинала.
