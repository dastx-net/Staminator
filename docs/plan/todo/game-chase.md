# Игровой режим: побег от преследователей

Вдохновиться [BabyType 2000](https://www.osp.ru/pcworld/1999/12/161176), где набор помогает персонажу спасаться от монстров.

**Предложение:** постепенно вводить новые буквы и препятствия, подстраивая сложность под игрока. Продумать движение персонажа, последствия ошибок и завершение уровня.

## Аналитика прототипа

**Основа:** это новая игра по мотивам другого продукта, не подтверждённая функция Stamina; правила и ресурсы создавать самостоятельно. Общие зависимости — [games.md](games.md).

**Предложение реализации:** персонаж движется по дистанции, преследователь сокращает разрыв с заданной скоростью; каждый верно набранный символ даёт продвижение, ошибка не продвигает. Упражнение разбивается на короткие фрагменты, показываемые заранее; достижение финиша завершает уровень, нулевой разрыв — проигрыш. Начать с выбранного урока и фиксированной сложности, без автоматической адаптации: это делает причину исхода понятной и воспроизводимой. Новые буквы вводить выбором следующего урока; адаптивность и препятствия требуют отдельного проектирования.

**Приёмка:** финал, поимка, ошибки, пауза и повтор с тем же seed и вводом воспроизводимы; при нулевой скорости ввода проигрыш предсказуем. Определить начальный разрыв и темп по результатам тестирования с пользователями.
