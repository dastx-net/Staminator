# Игровой режим: бег с препятствиями

По мотивам динозаврика Chrome придумать игру, где набор слов помогает прыгать и пригибаться.

**Предложение:** решить, как заранее показывать подходящую команду и давать время на набор, а также как меняются скорость и сложность препятствий.

## Аналитика прототипа

**Основа:** новая игра, аналог в исходниках Stamina не подтверждён; общие зависимости — [games.md](games.md).

**Предложение реализации:** каждое препятствие заранее показывает слово и действие («прыжок» или «пригнуться»); последовательный правильный ввод слова запускает указанное действие, ошибка не продвигает ввод. Слово закреплено за ближайшим препятствием, до его завершения следующая цель не выбирается. Окно реакции вычислять по расстоянию и скорости с минимальным временем, достаточным для выбранной сложности слова. При столкновении уровень заканчивается; при достижении дистанции показывается результат. Первую версию сделать с фиксированной скоростью и конечным набором препятствий; ускорение — после проверки удобства.

**Приёмка:** обе команды видны заблаговременно, верное слово запускает нужное действие, ошибка не засчитывается, поздний ввод приводит к столкновению. Пауза замораживает препятствия и таймер; одинаковые seed и события дают одинаковый результат. Конкретные интервалы подобрать опытным путём.
