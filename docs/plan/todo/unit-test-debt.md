# Долг по тестам и покрытию

**Приоритет:** первая очередь, вместе с [тестированием интерфейса](ui-testing.md), до новых продуктовых функций.

## Задача

Закрыть долг по автоматическим тестам текущего Rust workspace. Последний замер: 33,35% строк на Windows; требование — не менее 95% по всему workspace, включая desktop. Подробности и команда отчёта — в [документации тестов](../../unit-tests.md).

## Реализация

1. Обновить замер и изучить непокрытые строки по модулям; не исключать код ради процента.
2. Добавить поведенческие и граничные тесты ядра, форматов, генерации, профилей и сохранения. Проверить ошибки, восстановление и изоляцию данных.
3. Отделить состояние и зависимости desktop от отрисовки там, где это нужно для надёжных тестов. Дополнительно покрыть взаимодействия и рендеринг по [задаче UI](ui-testing.md).
4. Разобрать существующие замечания Clippy вместе с [задачей о правилах Rust](rust-code-quality.md). Локально запускать форматирование, Clippy, тесты и проверку 95%; до достижения порога отчёт честно показывает недостачу.

## Готовность

- `cargo test --workspace` проходит без реальных профилей и установки Stamina.
- `cargo llvm-cov --workspace --html --fail-under-lines 95` проходит на Windows; отчёт охватывает весь workspace без искусственных исключений.
- `cargo fmt --all -- --check` и `cargo clippy --workspace --all-targets -- -D warnings` проходят локально.
- Критичные сценарии и ошибки проверены по [плану QA](qa.md); системные ветви других ОС требуют отдельной проверки при их поддержке.

Не считать задачу выполненной только по проценту: тесты должны проверять результаты и значимые сценарии.
