# Импорт данных из Stamina

Решить, нужны ли перенос старых профилей и статистики, чтение уроков и фраз и поддержка прежних форматов. Перед распространением старых материалов необходимо проверить права.

Импорт отдельно скачанных EXE с дополнениями описан в [отдельной задаче](addon-import.md).

## Аналитика

**Оригинал:** `User.cpp`/`Options.cpp` используют профили и INI, `Progress.cpp` хранит результаты по раскладкам, `Lessons.cpp` и `Text.cpp` — уроки и фразы; кодировка установленных русских файлов — Windows-1251 ([исследование](../../research.md)). `crates/stamina-data` уже читает уроки, фразы и раскладки; это ещё не импорт профиля или истории.

**Реализация:** отдельный мастер с выбором каталога и предварительным отчётом: найденные пользователи, типы данных, ошибки, предлагаемые действия и конфликты. Исходник открывать только для чтения; импортировать выбранное в новую модель с новым ID и сохранением связи старого имени/раскладки. Сначала уроки/фразы, затем результаты и проверенные настройки; бинарный индекс фраз, плейлисты и произвольные скины не обещать до исследования. Кодировку определять по явному выбору при неоднозначности, не заменять неподдающиеся декодированию данные молча. Импорт одной порции выполнять в транзакции, повторный импорт распознавать по источнику и содержимому; конфликт решать через пропуск или создание копии. Вывести отчёт о пропущенных данных без раскрытия личных текстов.

**Приёмка:** импорт искусственной копии данных RU/EN, повреждённого INI и неоднозначной кодировки; проверить повтор, отмену и конфликт имён. Хеши исходных файлов до/после совпадают, ошибки не портят действующий профиль. Распространение старого контента — отдельная проверка прав.
