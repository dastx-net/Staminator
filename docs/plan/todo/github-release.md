# Подготовка к публикации на GitHub

Подготовить проект к открытой публикации, чтобы сообщество могло пользоваться им и участвовать в разработке.

Проверить состав и историю репозитория на личные данные, секреты, профили, результаты сборки и материалы, которые нельзя распространять. Выяснить права на исходники и ресурсы Stamina, FMOD, JPEG-компоненты и другие зависимости; отдельно решить, какие материалы можно включить в публичный репозиторий. Для нового кода выбрана MIT в пределах прав авторов; совместимость прав и допустимость публикации ещё не проверены ([ADR](../../adr/0003-license.md)).

**Предложение:** подготовить инструкции для участников, правила сообщений об ошибках и процесс сборки и проверки проекта. Отдельно продумать публичные сборки и выпуск версий; само наличие репозитория не означает готовность распространять все ресурсы.

## Аналитика первой очереди

**Контекст:** исходники и сторонние компоненты оригинала перенесены в отдельный локальный репозиторий `../Stamina`. `src/stamina_setup` исключён через `.gitignore`. Права и лицензии пока не установлены; поведение оригинала не определяет правила публикации проекта.

**Реализация подготовки.** Составить инвентаризацию каждого распространяемого исходника, шрифта, изображения, аудио и зависимости: происхождение, лицензия, подтверждение, условия, решение о включении. Для исходников Stamina, FMOD и JPEG получить подтверждение прав отдельно; собственные ресурсы тоже проверить. Проверить текущие отслеживаемые файлы и все коммиты на секреты, личные профили, локальные пути и закрытые материалы; обнаруженные секреты считать скомпрометированными и отозвать, очистку истории планировать отдельно. Подготовить чистый публичный состав только после решения по правам; не удалять имеющиеся библиотеки автоматически.

Добавить инструкцию сборки и запуска без установленной Stamina, условия контрибуций, шаблоны issue и CI `cargo test --workspace`; включить проверку зависимостей и лицензий, а найденные исключения разбирать вручную. Проверить совместимость выбранной лицензии с правами и зависимостями; публичные бинарные релизы и включение данных — отдельные решения с проверкой состава артефакта. Не публиковать до закрытия правовых и приватных блокеров.

Проверить `cargo-deny` для уязвимостей, источников и лицензий; утвердить политику лицензий после инвентаризации. Инструмент пока не установлен и проверка не выполнена.

## Проверка локального репозитория

- Из истории локальной ветки удалён `src/stamina`, ранее содержавший 181 отслеживаемый файл. Исходная история сохранена в локальный bundle в `target/github-preparation`; он не предназначен для публикации.
- `src/stamina_setup` игнорируется; коммитов с этим каталогом не найдено. Полная проверка истории на личные данные и секреты ещё нужна.
- Настроен remote `origin`; GitHub CLI не авторизован. В истории указаны локальные имя и email автора; перед публикацией подтвердить допустимость их раскрытия.
- Пользователь подтвердил, что фоновые изображения приложения сгенерированы для проекта с AI-ассистентом; условия использованного сервиса ещё нужно проверить. Скриншот в `src/materials` оставлен по решению пользователя; права на изображённые материалы не подтверждены.
- Проверить содержимое упражнений и зависимости. Удаление оригинальных исходников само по себе не закрывает проверку прав на новую реализацию.

**Приёмка:** чистый checkout собирается и запускается без локальной установки и персональных файлов; проверены содержимое и история, список зависимостей и ресурсов с подтверждёнными правами, лицензия и инструкции. CI проходит. Если право на исходники или ресурс не установлено, соответствующий материал и зависящий от него релиз остаются заблокированными. Юридическое заключение и фактическая проверка истории в рамках этой аналитики не выполнены.
