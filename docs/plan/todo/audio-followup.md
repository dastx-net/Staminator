# Музыка и эффекты: оставшиеся задачи

Первая реализация описана в [выполненной задаче](../done/audio.md).

- Добавить выбор эффекта для каждого события и управление музыкой: список, следующий трек и повтор.
- При ошибках эффектов не декодировать один повреждённый файл повторно и показывать ошибки чтения каталога.
- Переносить аудионастройки при экспорте и импорте отдельного профиля.
- Проверить на поддерживаемых ОС воспроизведение, отключение устройства, повреждённые и удалённые файлы, смену профиля и сохранение настроек. Проверить лицензии зависимостей перед распространением сборок и ресурсов.
