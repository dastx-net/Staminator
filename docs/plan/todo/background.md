# Фон

Разрешить отключать фон или загружать изображения в папку приложения и использовать их как фон.

**Предложение:** дать выбрать конкретное изображение, режим его размещения и затемнение для читаемости текста. Нужно решить, нужен ли случайный выбор из папки.

## Аналитика

**Оригинал:** `PageView.cpp` предлагает файл и цвет, `Stamina.cpp::LoadPicture` загружает картинку. Сейчас desktop использует локальный фон; наличие файла вне установки следует проверять, а не считать гарантированным.

**Реализация:** выбор «цвет» или «изображение», файловый диалог и пользовательский каталог данных с ручным обновлением списка. Для изображения предложить вписать, заполнить и замостить; регулируемый слой затемнения и предпросмотр. На профиль сохранять путь/идентификатор, режим и затемнение. Декодировать вне частой отрисовки, ограничить размеры и объём декодированного изображения, не хранить копию без явного импорта. При ошибке показать причину и использовать однотонный фон. Начать с PNG/JPEG после проверки возможностей декодера; случайный выбор оставить отдельной задачей.

**Приёмка:** пользователь выбирает фон, меняет режим и перезапускает приложение; отсутствующий, повреждённый и слишком большой файл не мешают тренировке, текст остаётся читаемым.
