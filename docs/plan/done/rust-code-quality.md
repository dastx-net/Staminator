# Технический долг: строгие правила Rust-кода

**Приоритет:** первая очередь, вместе с долгом по тестам и проверкой интерфейса. Сейчас разработка локальная; CI нет и его внедрение в эту задачу не входит.

**Статус:** выполнено по критериям задачи. Порог покрытия пока не достигнут; аудит зависимостей и политика лицензий остаются открытыми в [задаче подготовки к публикации](../todo/github-release.md).

## Действующие правила

- Все crate наследуют правила workspace: `unsafe_op_in_unsafe_fn` и `clippy::undocumented_unsafe_blocks` запрещены. Clippy также проверяет все предупреждения через `-D warnings`.
- В `core` и `stamina-data` запрещён весь `unsafe`. В desktop он допустим для Windows API; каждый блок требует комментария `SAFETY` с его инвариантами.
- Из корня проекта запустите `./scripts/check.ps1`. Скрипт проверяет форматирование, Clippy, тесты и покрытие всех функций workspace; при любой ошибке возвращает ненулевой код. Для покрытия нужны `cargo-llvm-cov` и компонент LLVM из [инструкции](../../unit-tests.md).
- `cargo-deny` пока не установлен. Проверка уязвимостей, источников и лицензий не выполнена; политику лицензий нужно утвердить после инвентаризации. SonarQube не настроен.

## Область задачи

- **rustfmt:** `cargo fmt --all -- --check`, настройки при необходимости в `rustfmt.toml`. `.editorconfig` дополняет настройки редакторов, но не заменяет rustfmt. Не форматировать старые исходники Stamina.
- **rustc и Clippy:** `cargo clippy --workspace --all-targets --all-features -- -D warnings`; сначала исправить существующие замечания. Дополнительные правила выбирать по пользе, не включать целиком `restriction` и `nursery`. Общие правила задать в `[workspace.lints.rust]` и `[workspace.lints.clippy]`, подключив `[lints] workspace = true` в каждом crate. Локальные исключения обосновывать рядом с кодом.
- **Unsafe:** рассмотреть `forbid(unsafe_code)` для чистых crates после проверки. В desktop уже есть `unsafe` для Windows-звука (`apps/desktop/src/sound.rs`); там требуется отдельная политика и обоснование каждого блока, глобальный запрет сломает текущую сборку.
- **Зависимости:** проверить `cargo-deny` для известных уязвимостей, лицензий и источников; это не заменяет проверку прав на старые ресурсы. Альтернатива для уязвимостей — `cargo-audit`. Конфигурацию лицензий утверждать после инвентаризации.
- **Локальные проверки:** после устранения замечаний запускать форматирование, Clippy, тесты и покрытие из [плана QA](../todo/qa.md) на Windows; другие ОС проверять по мере готовности. Свести команды в удобный локальный запуск с ненулевым кодом при ошибке.
- **SonarQube:** по желанию использовать отдельный сервер для отчётности: анализ Rust интегрируется с Clippy и импортирует покрытие LCOV/Cobertura. Возможности зависят от установленной версии; интеграция не настроена.

## Приёмка

Правила и исключения документированы, каждый crate наследует общие настройки, проверки воспроизводимы локально. Существующие нарушения исправлены, старые исходники и ресурсы не изменены. При завершении этой задачи покрытие было 33,39%; порог достигнут позже в [связанной задаче](unit-test-debt.md).
