# Долг по тестам и покрытию

**Статус:** выполнено 8 ноября 2026 года. Системные проверки остаются в [задаче UI](../todo/ui-testing.md).

## Задача

Закрыт долг по автоматическим тестам текущего Rust workspace. Замер на Windows: 95,16% строк; требование — не менее 95% по всему workspace, включая desktop. Подробности и команда отчёта — в [документации тестов](../../unit-tests.md).

## Реализация

1. Обновить замер и изучить непокрытые строки по модулям; не исключать код ради процента.
2. Добавить поведенческие и граничные тесты ядра, форматов, генерации, профилей и сохранения. Проверить ошибки, восстановление и изоляцию данных.
3. Отделить состояние и зависимости desktop от отрисовки там, где это нужно для надёжных тестов. Дополнительно покрыть взаимодействия и рендеринг по [задаче UI](../todo/ui-testing.md).
4. Поддерживать [правила Rust](../done/rust-code-quality.md): локально запускать форматирование, Clippy, тесты и проверку 95%; до достижения порога отчёт честно показывает недостачу.

## Готовность

- `cargo test --workspace` проходит без реальных профилей и установки Stamina.
- `cargo llvm-cov --workspace --html --fail-under-lines 95` проходит на Windows; отчёт охватывает весь workspace без искусственных исключений.
- `cargo fmt --all -- --check` и `cargo clippy --workspace --all-targets -- -D warnings` проходят локально.
- Критичные реализованные сценарии и ошибки проверены по [плану QA](../todo/qa.md); системные ветви других ОС требуют отдельной проверки при их поддержке.

Не считать задачу выполненной только по проценту: тесты должны проверять результаты и значимые сценарии.

Проверены разбор контента, сеанс, профили и ошибки хранения, действия интерфейса через AccessKit и отрисовка в egui. Ручные системные проверки, снимки и сравнение с оригиналом остаются открытыми в задаче UI и плане QA.
