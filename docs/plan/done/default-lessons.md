# Замена встроенных уроков

Заменить уроки Stamina по умолчанию русскими и английскими курсами из свободного репозитория, например KTouch. Проект должен иметь собственный набор уроков. Уроки Stamina пользователь сможет добавить через [импорт данных](../todo/legacy-import.md).

## Аналитика

**Источник:** локальный репозиторий `C:\Users\danie\source\repos\ktouch`; пример русского курса — [ru2.xml](https://github.com/KDE/ktouch/blob/master/data/courses/ru2.xml). Выбрать подходящие курсы для обеих раскладок; KTouch — пример источника, а не обязательный выбор.

**Реализация:** преобразовать выбранные курсы в [формат уроков приложения](../../lessons.md), сохранив порядок и группировку упражнений и задав стабильные ID. Включить их в поставку и использовать по умолчанию для русского и английского языков. Убрать уроки Stamina из встроенного набора и из автоматической загрузки по умолчанию. При обновлении заменить только встроенные уроки, сохранив пользовательские уроки, профили и результаты. Если выбранный ранее встроенный урок больше недоступен, выбрать доступный урок соответствующего языка. Зафиксировать источник материалов рядом с ними.

**Приёмка:** на чистой установке доступны русские и английские уроки из нового набора; можно выбрать и пройти урок и перейти к следующему. После обновления со старым набором новые уроки доступны, пользовательские уроки и результаты сохранены, отсутствующий прежний выбор не вызывает ошибку. Уроки Stamina доступны через отдельный импорт после его реализации.

## Статус

Реализованы курсы KTouch `us.xml` и `ru1.xml`, обновление встроенных уроков в SQLite и проверка сеансов. Источники и лицензионная оговорка — в [lessons/README.md](../../../lessons/README.md). До внешней публикации нужно подтвердить лицензию выбранных файлов и совместимость с лицензией проекта. Ручная проверка интерфейса и обновления запланирована отдельно.
