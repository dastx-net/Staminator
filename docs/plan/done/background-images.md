# Пользовательские изображения фона

Тренировка поддерживает встроенный пиксель-арт, однотонный фон и пользовательские PNG/JPEG. Изображение можно выбрать через диалог или из `%APPDATA%/Staminator/Backgrounds`; список обновляется вручную. Доступны предпросмотр, вписывание, заполнение, плитка и затемнение. Настройки сохраняются в профиле и резервной копии.

Широкий пиксель-арт создан встроенным инструментом генерации OpenAI для проекта. По умолчанию он заполняет окно. При миграции прежний встроенный фон в режиме вписывания без затемнения переводится в режим заполнения: явно выбранный режим с теми же параметрами отличить нельзя. Другие сохранённые настройки сохраняются.

Файлы не копируются. Лимиты: 32 МиБ на файл, 4096 пикселей на сторону, 64 МиБ на декодирование. Текстуры сверх предела видеоустройства уменьшаются при загрузке. При ошибке показывается причина и используется однотонный фон.

Автотесты проверяют загрузку, отрисовку, ошибки, смену профиля и сохранение. Окно клавиатуры перерисовывается отдельно от главного. Ручная проверка интерфейса и плавности изменения размера остаётся в QA. Случайный выбор из папки не реализован.

В оригинале `PageView.cpp` предлагает файл и цвет, а `Stamina.cpp::LoadPicture` загружает изображение. [Однотонный фон](background.md) реализован ранее.
