# Редактор и генерация уроков, добавление фраз

Создать встроенный редактор уроков, генератор упражнений и добавление фраз. Пользователь должен работать с материалами без ручного редактирования файлов.

Для уроков использовать [формат JSON](../../lessons.md) и общую валидацию каталога. Сохранять пользовательские данные через временный файл и замену; не изменять старые данные при ошибке. Уточнить формат хранения фраз и алгоритм генерации после исследования оригинала (`DlgLessons.cpp`, `DlgAddText.cpp`). Импорт старого формата остаётся [отдельной задачей](../todo/legacy-import.md).

Проверка: создать и изменить урок, сгенерировать упражнение, добавить фразу, пройти их и убедиться, что данные доступны после перезапуска. Проверить ошибки валидации и сохранения без потери существующих файлов.

Реализовано: редактор пользовательских уроков, генератор по шаблонам оригинала и добавление фраз. Автоматически проверены сохранение, ошибки, повторная загрузка и тренировка. Ручная проверка интерфейса остаётся в QA.
