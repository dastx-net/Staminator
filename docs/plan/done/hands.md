# Подсказка с руками

Сделать отдельное окно с нарисованными руками и растопыренными пальцами. Подсвечивать руку и палец, которыми нужно нажать следующую клавишу.

**Предложение:** связать подсказки с настройками клавиатуры, чтобы они соответствовали выбранной пользователем схеме. Подумать, нужна ли подсветка нескольких допустимых пальцев и как отображать сочетания с Shift.

## Реализация

Окно рук показывает палец следующей клавиши для RU/EN. Для пробела выделены оба больших пальца, для заглавного символа — палец клавиши и противоположный Shift. Неизвестные символы остаются без подсветки. Видимость и положение окна сохраняются в профиле; закрытие окна не останавливает занятие.

Сейчас окно использует фиксированные зоны клавиатуры. Выбор схем пальцев и общая модель назначений входят в задачу [настраиваемой клавиатуры](../todo/custom-keyboard.md). Ручная проверка системных окон и ввода остаётся открытой.

В оригинале зоны пальцев и активная клавиша есть в `KeybWnd.cpp` и `PageKeyb.cpp`; отдельное окно рук не подтверждено.
