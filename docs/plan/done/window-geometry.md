# Окна и их расположение

Сейчас окна появляются друг под другом. Нужно запоминать положение и размер каждого окна для каждого пользователя и восстанавливать их при следующем запуске.

**Предложение:** при отключении монитора или изменении его разрешения возвращать недоступное окно в видимую область. Также может пригодиться команда сброса расположения окон.

## Аналитика первой очереди

**Оригинал:** `KeybWnd.cpp::SetPosition` перемещает отдельное окно клавиатуры, а `Options.cpp` сохраняет её ширину и видимость. Это не доказывает восстановление произвольной геометрии каждого окна; поведение после перезапуска нужно проверить на копии. Раздельное сохранение по профилю — требование клона.

**Сейчас:** `apps/desktop/src/main.rs` создаёт главный viewport и отдельный `keyboard-window`; видимость клавиатуры сохраняется отдельно от профиля. Размер и позиция всех окон по профилю не реализованы.

**Реализация.** Хранить для профиля и стабильного ID окна нормальный прямоугольник в логических единицах, состояние развёрнутости и видимость; не сохранять свёрнутое состояние как стартовое. На первом этапе охватить главное окно и клавиатуру, затем добавлять постоянные окна по мере появления. Записывать изменения с debounce и при закрытии или смене профиля; восстановление делать после выбора профиля и появления информации о мониторах. Проверить конечность и разумные границы размера; при изменении DPI и отсутствии монитора подобрать видимый прямоугольник в рабочей области доступного монитора, обеспечив доступ к заголовку. При сбросе удалить сохранённую геометрию текущего профиля и применить значения по умолчанию. Не создавать скрытую клавиатуру при восстановлении.

На Wayland композитор может не предоставлять глобальные координаты или не принимать заданную позицию; при отсутствии API сохранять доступный размер и видимость, оставлять размещение системе и не обещать точное восстановление. Возможности viewport и мониторов используемой версии `egui`/бэкенда проверить прототипом до выбора платформенного адаптера; при смене профиля не переносить несохранённую геометрию предыдущего.

**Приёмка:** два профиля имеют независимые позиции и видимость после перезапуска; закрытие клавиатуры отключает соответствующую настройку. Проверить изменение размера, перемещение между мониторами с разным DPI, отключение монитора, повреждённые настройки и сброс. На Wayland отдельно проверить фактически доступный уровень восстановления.

**Ход работы:** главное окно и клавиатура сохраняют геометрию и видимость по профилю. Команда «Сбросить расположение окон» находится в меню опций. Изменения сохраняются с задержкой и перед закрытием или сменой профиля. В Windows недоступное окно возвращается в рабочую область; сохранённый масштаб помогает пересчитать положение при смене DPI. `egui` 0.37 не предоставляет список рабочих областей, поэтому для Windows используется адаптер `window_monitors.rs`. На других системах список недоступен; на Wayland позицию задаёт композитор. Остались ручные проверки двух мониторов с разным DPI, отключения монитора и Wayland.
