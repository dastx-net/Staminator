# Музыка и звуковые эффекты

**Статус:** воспроизведение пользовательской музыки и звуковых эффектов реализовано. Ручная проверка, выбор звуков для событий и другие улучшения вынесены в [следующую задачу](../todo/audio-followup.md).

Как и для уроков, предусмотреть папки, в которые пользователь сможет добавлять свои музыкальные файлы и звуковые эффекты. Приложение должно находить добавленные файлы и позволять их использовать.

**Предложение:** дать возможность назначать эффекты событиям, отдельно регулировать громкость музыки и эффектов и отключать их. Для музыки можно предусмотреть плейлист и случайное воспроизведение. Нужно выбрать поддерживаемые форматы, способ обновления списка файлов и расположение папок на разных операционных системах.

## Аналитика

**Оригинал:** `Sound.cpp`, `Music.cpp`, `DlgPlaylist.cpp` и `PageSound.cpp` реализуют эффекты, плейлист и отдельную громкость через FMOD.

**Сейчас:** папки `Music` и `Sound` создаются в каталоге приложения, в Windows обычно `%APPDATA%/Staminator`. Окно звука показывает число WAV и MP3, позволяет обновить список и сохраняет отдельные уровни громкости и выключатели для каждого профиля. Файлы из `Music` воспроизводятся в случайном порядке. При ошибке ввода файлы из `Sound` воспроизводятся по очереди; при пустой папке используется системный звук Windows. Звуки старта и паузы остаются системными. Громкость системных звуков задаётся Windows. Звук на целевых ОС и лицензии зависимостей требуют проверки.

Настройки звука пока не переносятся при экспорте и импорте отдельного профиля; резервная копия базы сохраняет их.

**Проверки:** автоматические тесты проверяют профили, случайный порядок, ошибки файлов и восстановление аудиоустройства через тестовый адаптер. Реальное воспроизведение и поддержка целевых ОС требуют ручной проверки. Порог покрытия workspace в 95% пока не достигнут.
