# Каталог уроков

Хранить уроки в папке приложения как иерархию папок и JSON-файлов. Для добавления нового урока пользователь помещает его в папку.

Продумать встроенный редактор и генерацию уроков, а также добавление фраз: это позволит работать с материалами без ручного редактирования файлов.

**Предложение:** предусмотреть название, язык, описание и версию формата урока. Приложение должно сообщать о некорректном файле понятным образом, не мешая открывать остальные уроки. Стоит отдельно решить, как обновлять список после добавления файлов и где расположить пользовательскую папку, чтобы обновление приложения её не затронуло.

## Аналитика первой очереди

**Оригинал:** `Lessons.cpp` читает один файл уроков на раскладку с маркерами разделов и текстовых уроков; `GetNextTextLessonID` и `GetPrevTextLessonID` пропускают разделы. `DlgLessons.cpp` содержит редактор и генерацию, `DlgAddText.cpp` — добавление фраз. Точная семантика всех маркеров и генератора ещё требует исследования. Новый JSON — пожелание проекта, а не формат оригинала.

**Сейчас:** `apps/desktop/src/content.rs` через `stamina-data` читает старые файлы только для чтения, с резервными упражнениями. Это зависит от локальной установки, которую нельзя считать поставляемым контентом.

**Реализация.** В первой очереди создать каталог JSON-файлов: один файл — один урок, вложенные папки — группы. Предлагаемая схема v1: `version: 1`, стабильный `id`, `title`, BCP 47 `language`, необязательное `description`, непустое `text`; UTF-8, пример и правила ограничений документировать рядом с реализацией. ID уникален в каталоге; при дубликате не выбирать победителя молча, сообщить пути конфликтов. Сканировать встроенный каталог и пользовательский каталог данных приложения рекурсивно, сортировать детерминированно, не следовать ссылкам за пределы корня. Добавить явную команду обновления списка; ошибки отдельного файла показывать с путём и причиной, остальные уроки загружать. Выбор хранить по ID, а не индексу. Пользовательский каталог не перезаписывать при обновлении; пример урока создать собственный.

[Редактор, генерация и добавление фраз](lesson-editor.md) реализованы отдельно. Импорт старого формата — отдельная операция после решения о правах.

**Приёмка:** добавить валидный файл во вложенную папку и обновить список без перезапуска; пройти его и перейти к следующему. Проверить пустой текст, неверный JSON, неизвестную версию и дубликат ID: диагностика видна, другие уроки доступны. Обновление приложения не удаляет пользовательские файлы.

## Состояние первой очереди

Каталог JSON, обновление списка и диагностика реализованы. Формат и расположение описаны в [справке](../../lessons.md). [Редактор, генерация и добавление фраз](lesson-editor.md) реализованы. Ручная проверка настоящего окна и сценария обновления приложения ещё нужна.
