# Масштаб окон

В окнах с руками, клавиатурой и текстом предусмотреть увеличение и уменьшение с помощью Ctrl + и Ctrl −, а также Ctrl + колёсико мыши.

**Предложение:** сохранять масштаб каждого окна отдельно и добавить сброс к исходному размеру, например через Ctrl + 0. Проверить удобство сочетаний на разных раскладках и при масштабировании Windows.

## Аналитика

**Оригинал:** `KeybWnd.cpp` масштабирует геометрию клавиатуры от ширины окна; `Options.cpp` хранит ширину и параметры шрифтов. Сочетания Ctrl с колёсиком исходниками не подтверждены. Клавиатура рисуется пропорционально доступной области (`keyboard.rs`).

**Реализация:** ввести независимый множитель содержимого каждого окна (предложение: 0,5–3,0, шаг 0,1, Ctrl+0 — 1,0), хранить по профилю и ID окна отдельно от размера окна. Ctrl+плюс/минус и Ctrl+колесо действуют только в фокусе соответствующего окна; обрабатывать физические и символные варианты плюс с учётом раскладки, не отправлять сочетание в сеанс. Ограничить масштаб и предусмотреть прокрутку, не обрезая элементы. Системный DPI применять один раз, без повторного умножения. При отсутствии API отдельного viewport предусмотреть локальное масштабирование содержимого.

**Приёмка:** каждое окно меняет масштаб независимо, сброс и перезапуск работают; RU/EN, цифровой блок, фокус поля и системный DPI не приводят к вводу ошибок или двойному масштабированию. Проверить конфликты с обработкой egui на каждой ОС.

**Ход работы:** добавлены независимый масштаб содержимого главного окна, клавиатуры и рук, диапазон 0,5–3,0, шаг 0,1 и сброс Ctrl+0. Значения сохраняются по профилю и ID окна. Сочетания и Ctrl+колесо перехватываются до ввода в сеанс; встроенный масштаб egui отключён. В окнах клавиатуры и рук при увеличении доступна прокрутка; текст тренировки перемещается вместе с курсором. Автоматические тесты проверяют хранение, границы и ввод. Покрытие workspace — 95,05% строк. Остаются ручные проверки RU/EN, цифрового блока, фокуса, DPI и поведения на поддерживаемых ОС.

**Перенос профиля:** экспорт и импорт сохраняют масштаб трёх окон; резервная копия базы сохраняет все настройки.
