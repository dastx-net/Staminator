# База данных и хранение

**Статус:** реализовано. Ручная проверка окон и переноса между компьютерами остаётся в [плане UI](../todo/ui-testing.md).

## Данные и миграции

SQLite хранит уроки, профили, результаты, язык профиля и настройки приложения. При первом запуске прежние `profiles.json` и JSON-уроки импортируются без удаления исходных файлов. Встроенные уроки обновляются из файлов при запуске, пользовательские уроки и группы сохраняются в базе. Пользовательские фразы хранятся отдельно.

Версия схемы записана в `PRAGMA user_version`. Миграции выполняются последовательно, каждая в транзакции; более новая неизвестная версия отклоняется. Схема v2 добавляет причину остановки; для прежних результатов используется `unknown`. Исходные данные результатов и импортированные метрики сохраняются.

Результат и позиция внешнего файла сохраняются вместе. Хранится до 10 000 результатов на профиль. Обычное добавление результата не перезаписывает прежние записи. Устаревшая версия профилей не может затереть данные другого экземпляра: приложение сообщает о конфликте и предлагает перезапуск.

## Копирование и перенос

В «Опциях» доступны создание, проверка и восстановление резервной копии базы. Восстановление проверяет копию, сохраняет текущую базу в `pre-restore-*.sqlite3` и заменяет данные транзакционно. Для восстановления нужна копия поддерживаемой версии схемы. Фразы и внешние текстовые файлы не входят в копию базы.

Урок можно экспортировать или импортировать через окно выбора урока; профиль с историей — через окно пользователей. JSON-файлы имеют кодировку UTF-8; экспорт не перезаписывает существующий файл. При совпадении имени или ID импорт профиля отклоняется. Путь внешнего файла в профиле может измениться при переносе: тогда выберите файл заново.

В Windows база находится в `%APPDATA%/Staminator/staminator.sqlite3`. На других платформах используется каталог конфигурации `Staminator`; пользовательские фразы могут находиться в отдельном каталоге данных `Staminator/phrases`. Для ручного копирования закройте приложение и перенесите оба каталога.

## Метрики и оригинал

Сохраняются верные нажатия, ошибки, активное время, скорость, процент ошибок и причина завершения. Ядро считает скорость как `correct × 60000 / elapsed_ms` с округлением половины вверх; при нулевом времени скорость равна нулю. Процент ошибок — `errors × 100 / (correct + errors)`, при нулевом числе нажатий — ноль. Ранее сохранённые метрики не пересчитываются.

В оригинале `User.cpp` и `Options.cpp` хранят настройки в INI, `Progress.cpp` записывает историю по профилю и раскладке, а `Stamina.cpp::StopGame` сохраняет только фразы и файл при длительности не менее 120 секунд. Новое приложение сохраняет результаты по своей прежней политике. Журнал каждого нажатия рассматривается отдельно в [плане журнала](../todo/session-log.md).

Миграция, восстановление, конфликты записи, перенос профиля и урока, группы и обновление встроенных уроков проверяются тестами. Реальный перенос между компьютерами и ручная проверка диалогов остаются в общем плане UI.

Замечания ревью об ошибках переноса уроков и диагностике файлов исправлены. Повторное ревью завершилось без P0/P1; финальная проверка следующих правок не завершилась из-за отклонённой команды в headless-режиме Antigravity.
