# Недоверенные ветки в CI

**Решение:** собираемая ветка не управляет тем, что выполняется на сервере сборки. Pipeline хранится в конфигурации задачи Jenkins, образ и публикация результата берутся из `master`. Код ветки работает только в контейнере без сети и без `.git`, с отдельным кешем сборки. `master` меняется только через pull request. Бот не пушит правки `automation/`, `.github/` и `.cargo/` без разрешения инициатора.

**Почему:** ветки пишет Codex, на которого влияют тексты issue, зависимости и веб. Агент Jenkins имеет доступ к Docker, то есть root на домашнем сервере с ключами VPN и другими проектами. Раньше `Jenkinsfile` из любой ветки выполнялся на хосте, а сборка видела домашнюю сеть и прокси.
