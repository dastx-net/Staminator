# Покрытие тестами

**Решение:** не менее 95% покрытия строк тестами для всего Rust workspace, включая desktop.

**Почему:** отслеживать непроверенный код и не допускать снижения качества при доработках.

**Подробности:** [unit-тесты и отчёт](../unit-tests.md). Порог достигнут на Windows; метрику проверяют при дальнейших изменениях.
