# UTF-8 для новой реализации

**Решение:** новые текстовые файлы проекта и внешние тексты тренировок используют UTF-8. Файл с неверной кодировкой отклоняется с сообщением об ошибке. UTF-8 с BOM поддерживается; BOM не входит в текст для набора.

**Границы:** исходники и данные оригинала в `../Stamina` и `src/stamina_setup` не перекодируются. Чтение наследуемых уроков и раскладок сохраняет поддержку Windows-1251.

**Проверка:** `scripts/check-utf8.ps1` проверяет собственные текстовые файлы проекта; `scripts/check.ps1` запускает её вместе с остальными проверками.
