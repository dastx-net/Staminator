# Каталог уроков

**Решение:** хранить каждый урок в UTF-8 JSON v1. Встроенные и пользовательские файлы читаются из отдельных каталогов. Выбор в сеансе привязан к ID; конфликтующие ID исключаются с диагностикой.

**Почему:** уроки можно добавлять без редактирования общих файлов, а обновление программы не затрагивает пользовательские материалы.

**Ограничения:** интерфейс пока поддерживает русский и английский. Редактор и импорт старого формата остаются отдельными задачами. Подробности и формат — в [справке](../lessons.md).
