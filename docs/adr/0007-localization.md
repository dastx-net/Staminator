# Формат переводов интерфейса

**Решение:** встроенные переводы хранятся в UTF-8 JSON по языкам. Базовый язык — русский. Язык хранится в профиле отдельно от языка упражнений и раскладки. При отсутствии ключа используется русская строка и записывается диагностика.

**Почему:** для двух встроенных языков достаточно строк, именованных подстановок и форм множественного числа. JSON доступен участникам без специальных инструментов. Внешняя установка языков и правила для других языков требуют отдельного решения.

**Подробности:** [локализация](../localization.md).
