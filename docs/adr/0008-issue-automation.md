# Автоматизация issue через Codex

**Решение:** issue, назначенные на `losinkatorf` доверенным инициатором, решает бот на easy-day под отдельной учёткой `stamibot`. Стадии: план, ревью плана, реализация, ревью реализации, CI, pull request. Реализует `gpt-6-sol`, ревьюит `gpt-6-astra`. События бот получает опросом GitHub раз в минуту. CI идёт в локальном Jenkins. Бот не начинает ход Codex при расходе лимита от 75%.

**Почему:** простые задачи не должны ждать человека. Отдельная учётка ограничивает ущерб от ошибок агента. Опрос работает за NAT без публичного входа. Разные модели для реализации и ревью дают независимую проверку.
