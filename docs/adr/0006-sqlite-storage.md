# Хранение данных в SQLite

**Решение:** хранить уроки, профили, результаты и настройки приложения в SQLite. JSON остаётся входным форматом существующих уроков и профилей. Исходные файлы при миграции не удаляются.

**Причина:** пользователь запросил единое хранилище уроков и данных приложения. Это решение заменяет файловое хранение уроков из [ADR 0005](0005-lessons.md).

**Ограничения:** пользовательские фразы и внешние тексты остаются отдельными файлами. Ручная проверка переноса и диалогов ведётся отдельно. Подробности: [хранение](../plan/done/storage.md).
