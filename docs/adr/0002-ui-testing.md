# Тестирование интерфейса

**Решение:** проверять логику UI автоматическими Rust-тестами, взаимодействия и ключевые экраны — тестами egui, а системный ввод и окна — на реальной ОС. Проверить `egui_kittest` на прототипе до внедрения.

**Почему:** ни unit-тесты, ни снимки экрана по отдельности не проверяют весь пользовательский сценарий и работу оконной системы.

**Подробности:** [тестирование интерфейса](../ui-tests.md). Инструмент и автоматизация пока не внедрены.
